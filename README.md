## 🛠️ Installation

## Step 1: Inventory Integration

#### For QBCore (`qb-inventory`) (or any other inventory)
1. Copy items from `md-houserobberies/items_install/qb-inventory` into `qb-core/shared/items.lua`.
2. Add item images from `md-houserobberies/items_install/images` to `qb-inventory/html/images`.

#### For OX_Inventory
1. Copy items from `md-houserobberies/items_install/ox_inventory` into `ox_inventory/data/items.lua`.
2. Add item images from `md-houserobberies/items_install/images` to `ox_inventory/web/images`.


## Step 2: Configuration

- Modify `md-houserobberies/config.lua` and `md-houserobberies/server/server_config` to your liking
